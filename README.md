# Thunder Fitness

Concept mockups built for the Thunder Fitness pitch (Livermore / Newark / San Jose).

## ThunderCharge

A gamified member and trainer app: check in, earn points, climb the leaderboard, unlock exclusive gear.

- **Landing page** — `index.html`
- **Member/trainer app** — `thundercharge/member-app.html`
- **TV signage board** — `thundercharge/tv-signage.html`
  Rotating leaderboard display for gym monitors. Responsive for both landscape and portrait TVs, and includes a "Join the Movement" panel with a scannable QR code linking to the member app.

Served live via GitHub Pages at https://muso-ventures.github.io/Thunder-Fitness/
